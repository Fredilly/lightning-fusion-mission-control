# HOPE Fusion Mission Control

Interactive executive mission-control prototype for Lightning Fusion / HOPE.

## What it demonstrates

- Program-gate tracking from plasma stability to positive-energy validation
- Interactive experiment-scenario model
- 2026–2035+ commercialization roadmap
- Deck-grounded executive intelligence prompts
- Responsive presentation suitable for a CEO demo

## Important

All experiment scenario outputs are illustrative demo data. The prototype does not claim to perform plasma-physics simulation and is not connected to live company systems.

## Local development

```bash
npm install
npm run dev
```

## Deploy

The project is designed for Vercel and can be imported directly from this GitHub repository.
